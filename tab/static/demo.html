The same thing, for a machine

One endpoint. Anything can call it.

The page you just used is a thin wrapper over one HTTP call. That is the whole integration surface — no SDK, no account, no webhook registration. If your tool can POST a file, it can use TAB.

# send a receipt, get a verdict
curl -X POST $TAB/api/check \
  -H "X-Filename: receipt.jpg" \
  --data-binary @receipt.jpg
# what comes back
{
  "verdict": "needs_review",
  "why": "line 3: 3.0 × ₱30.00 is ₱90.00, but the line reads ₱80.00",
  "route": "ocr",
  "seconds": 0.9,
  "flagged": ["subtotal", "item.3.amount"],
  "receipt": { /* merchant, date, totals, line items */ },
  "checks": [ /* every check, with pass / fail / skip */ ],
  "stored": false
}

Branch on verdict, not on a confidence score. There isn’t one, on purpose. A model that tells you it is almost certain will state a wrong total with exactly that much conviction. verdict is the output of arithmetic that either reconciles or doesn’t, so it means something you can route on.

A check can also come back skip, which is not a pass. It means that check could not run — the receipt didn’t print the numbers it needed. A receipt where everything skipped has been read, not verified, and TAB holds it back rather than filing it.

Unattended

Where this fits in an n8n flow.

n8n is a tool where you wire boxes together instead of writing glue code — “when an email arrives, do this, then that”. TAB is one box in the middle: the one that decides whether a receipt is trustworthy enough to file without a person looking at it.

triggerGmailA receipt lands in your inbox with an attachment.
stepExtract filePull the attachment out of the message.
thisPOST /api/checkTAB reads it and checks the arithmetic. ~1 second.
stepSwitchLook at verdict. Two ways out.
endSheets / SlackFile the good ones. Ask about the rest.
verdict = commitAppend to Google Sheets The arithmetic reconciled. The row goes straight into the sheet and nobody is interrupted.
verdict = needs_reviewMessage you on Slack Send why and flagged, so the message says which line disagrees instead of just “check this”.

The workflow is in the repo as n8n/tab-receipt-check.json. In n8n: Workflows → Import from File, then set the TAB URL in the one HTTP node. The interesting part is the Switch — it is the reason the flow can be left alone. Every receipt that adds up files itself, and the only ones that reach you are the ones a person actually needs to look at.
